# Python_atm_machine

A simple beginner-friendly ATM Machine project built using Python.  
This project simulates basic ATM operations using loops and conditional statements.

---

## Features

- Check Balance
- Deposit Money
- Withdraw Money
- Exit System

---

## Technologies Used

- Python

---

## Project Structure

```text
python-atm-machine/
│
├── ATM machine.py

```

---

## How to Run

Run the following command in terminal:

```bash
python ATM machine.py
```
